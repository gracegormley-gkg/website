```css
/* style.css — Grace Gormley Portfolio Design System */
/* Fonts loaded via <link> in every page <head>:
   Newsreader: ital,opsz,wght@0,6..72,300..800;1,6..72,300..800

:root {
  /* Typography */
  --font-editorial: 'Newsreader', Georgia, serif;
  --font-ui: 'Inter', system-ui, sans-serif;

  --text-xs:   0.75rem;
  --text-sm:   0.875rem;
  --text-base: 1rem;
  --text-lg:   1.125rem;
  --text-xl:   1.5rem;
  --text-2xl:  2rem;
  --text-3xl:  2.75rem;

  --leading-tight: 1.2;
  --leading-body:  1.6;
  --leading-loose: 1.8;

  /* Colors — editorial neutral palette */
  --color-ink:          #1a1a1a;
  --color-ink-muted:    #555555;
  --color-border:       #e0e0e0;
  --color-bg:           #ffffff;
  --color-bg-subtle:    #f9f8f6;
  --color-accent:       #1a3a5c;
  --color-link:         #1a3a5c;
  --color-link-hover:   #0f2540;

  /* Spacing — 8px grid */
  --space-1:  0.25rem;
  --space-2:  0.5rem;
  --space-3:  0.75rem;
  --space-4:  1rem;
  --space-6:  1.5rem;
  --space-8:  2rem;
  --space-12: 3rem;
  --space-16: 4rem;
  --space-24: 6rem;

  /* Layout */

  --max-width-wide:   1100px;
  --border-radius:     4px;
  --transition-fast:   150ms ease;
}
```

**Section 3 — Base typography** (element selectors only, no class names):
```css
body {
  font-family: var(--font-ui);
  font-size: var(--text-base);
  line-height: var(--leading-body);
  color: var(--color-ink);
  background: var(--color-bg);
}

h1, h2, h3, h4 {
  font-family: var(--font-editorial);
  line-height: var(--leading-tight);
}

a {
  color: var(--color-link);
  text-decoration: underline;
  text-underline-offset: 2px;
}

a:hover {
  color: var(--color-link-hover);
}
```

**Stop here.** Do NOT add layout rules, class-based rules, flexbox containers, grid definitions, card styles, or any rule that references a specific HTML element that doesn't exist yet. If a CSS rule requires a class name, it does not belong in Phase 1.
