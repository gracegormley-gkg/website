SiteNav implementation:
- Class SiteNav extends HTMLElement
- connectedCallback() reads: `const path = window.location.pathname.split('/').pop() || 'index.html';`
  The `|| 'index.html'` fallback is mandatory — GitHub Pages serves index.html at the repo root URL where pathname ends in `/`, making pop() return an empty string. Without the fallback, the About nav link is never highlighted on the home URL.
- Nav links array (href and label, in this order):
  - index.html / About
  - clips.html / Clips
  - photos.html / Photography
  - video.html / Video
  - knight-lab.html / Knight Lab
  - suso-camp.html / SUSO Camp
  - awards.html / Awards
- Sets this.innerHTML to a <nav class="site-nav"> containing:
  - <div class="site-nav__brand"><a href="index.html">Grace Gormley</a></div>
  - <ul class="site-nav__links"> with <li><a> for each link
  - Active link gets class="active" when path === l.href (inline ternary in template literal)
- customElements.define('site-nav', SiteNav)

SiteFooter implementation:
- Class SiteFooter extends HTMLElement
- connectedCallback() sets this.innerHTML to a <footer class="site-footer"> containing:
  - <a href="mailto:gracegormley@gmail.com">gracegormley@gmail.com</a>
  - &nbsp;&mdash;&nbsp;
  - <a href="https://www.linkedin.com/in/grace-gormley/" target="_blank" rel="noopener">LinkedIn</a>
  - rel="noopener" is required on the target="_blank" LinkedIn link (security best practice)
- customElements.define('site-footer', SiteFooter)

Do NOT use Shadow DOM (no this.attachShadow). Do NOT use `defer` on external script — module scripts are already deferred by the browser.
